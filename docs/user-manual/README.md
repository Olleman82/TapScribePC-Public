# TapScribe användarmanual

Den här manualen är till för dig som vill använda TapScribe i vardagen utan att läsa tekniska detaljer.

## Vem manualen är för

- Du som dikterar text med snabbkommandon.
- Du som kör mötestranskribering från ljudfiler.
- Du som vill återanvända AI-prompter och historik.
- Du som hjälper andra att komma igång i teamet.

## Så använder du dokumentationen

- Börja med `01-kom-igang.md` om du är ny.
- Gå vidare till kapitlet som matchar din uppgift just nu.
- Använd `_meta/spårbarhet-mot-kod.md` när innehåll ska verifieras inför release.

## Kapitelöversikt

- `docs/user-manual/00-ordlista.md` - begrepp och grundtermer.
- `docs/user-manual/01-kom-igang.md` - första start och basinställningar.
- `docs/user-manual/02-live-diktering.md` - F8/F9, autoklistra och status.
- `docs/user-manual/03-ai-bearbetning.md` - AI-flöde, API-nycklar och datagräns.
- `docs/user-manual/04-promptar-och-minne.md` - promptar, minne, webhook och mail-läge.
- `docs/user-manual/05-modeller-och-prestanda.md` - modellval, AutoTune, VAD.
- `docs/user-manual/06-moten-och-talarigenkanning.md` - mötestranskribering och diarization.
- `docs/user-manual/07-batchko.md` - batchkörning av flera filer.
- `docs/user-manual/08-historik.md` - sök, filter och rensning.
- `docs/user-manual/09-installation-uppdatering-och-integritet.md` - drift och integritet.
- `docs/user-manual/10-felsokning.md` - symptom, orsak och åtgärder.
