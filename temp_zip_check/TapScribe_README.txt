Tack för att du laddat ner TapScribe! 
Här är en snabbguide för att komma igång på ett säkert och smidigt sätt.

OM TAPSCRIBE
------------
TapScribe är ett verktyg för yrkesverksamma som behöver snabb och privat 
dikttering. All transkribering sker LOKALT på din dator – inget ljud 
skickas någonsin till molnet.

INSTALLATIONSANVISNINGAR (Windows SmartScreen)
---------------------------------------------
Eftersom TapScribe är ett oberoende open source-projekt är det inte 
digitalt signerat. Windows kan därför varna vid första start. 

STEG 1: Standardinstallation (Rekommenderas)
1. Ladda ner och kör 'TapScribe-Setup.exe'.
2. Om blå varningsruta ("Windows har skyddat din dator") visas:
   - Klicka på 'Mer info'.
   - Klicka på 'Kör ändå'.
3. Följ instruktionerna för att installera appen.

STEG 2: Om appen blockeras helt av IT-policy
Vissa organisationer har striktare säkerhetsregler där installatörer 
inte får köras. Om Steg 1 inte fungerar:
1. Ladda ner zip-filen 'TapScribe.zip'.
2. Högerklicka på zip-filen (innan du packar upp den).
3. Välj 'Egenskaper'.
4. Längst ner under fliken 'Allmänt', leta efter 'Säkerhet' och 
   kryssa i rutan 'Avblockera' (Unblock). Tryck OK.
5. Packa upp innehållet till en mapp på din dator.
6. Om 'TapScribe.exe' fortfarande blockeras: Högerklicka på filen, välj 'Egenskaper' och välj 'Avblockera' även här.
7. Dubbelklicka på 'TapScribe.exe' inuti mappen.

STEG 3: Smidigare åtkomst (för Zip-versionen)
Om du kör zip-versionen, högerklicka på 'TapScribe.exe' och välj 
'Skapa genväg' för att enkelt kunna starta appen från skrivbordet.
